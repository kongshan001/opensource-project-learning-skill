# Quick Start Guide

Get started with the Open Source Project Learning Skill in 3 minutes.

## 🚀 Installation

### Option 1: Claude Code (Recommended)

```bash
# Create the skills directory if it doesn't exist
mkdir -p ~/.claude/skills/

# Copy the skill file
cp SKILL.md ~/.claude/skills/opensource-project-learning.md
```

### Option 2: Other AI Platforms

Copy the contents of `SKILL.md` and add it to your AI's prompt/instructions.

## 📖 Usage

### Basic Usage

When you want to learn a new open-source project, just say:

```
"Help me learn the [project-name] project"
```

The skill will guide you through:
1. Installing and running the project
2. Understanding what it does
3. Exploring how it works

### Example Sessions

#### Learning a CLI Tool
```
You: "Help me learn the eslint project"

AI: "This is a JavaScript linting tool that finds and fixes problems in your code.
Its core value is catching bugs before runtime.

What interests you most:
1. How to install and try it
2. What problems it can find
3. Other aspects"
```

#### Learning a Web Framework
```
You: "Help me learn the Next.js project"

AI: "This is a React framework for building full-stack web applications.
Its core value is simplifying React development with built-in routing and rendering.

What interests you most:
1. How to create a new app
2. What makes it different from plain React
3. Other aspects"
```

#### Learning an API Library
```
You: "Help me learn the axios project"

AI: "This is an HTTP client for making API requests in JavaScript.
Its core value is providing a simple interface for complex HTTP operations.

What interests you most:
1. How to make your first API call
2. What features it has over fetch()
3. Other aspects"
```

## 🎯 Tips for Best Results

### 1. Be Honest About Your Level
```
"I'm new to JavaScript"
"I've never used a database before"
"I don't understand what 'context window' means"
```

### 2. Set Time Expectations
```
"I only have 10 minutes"
"I want a deep dive into the architecture"
"Just give me the highlights"
```

### 3. Ask Questions
```
"Why did they choose that approach?"
"What would happen if I changed this?"
"Is there a simpler way to do this?"
```

### 4. Connect to Your Experience
```
"This reminds me of [other project]"
"I use something similar at work called [X]"
"I tried this before and got stuck on..."
```

## 🔧 Advanced Usage

### Learning by Problem-Solving
```
"I want to understand how this project handles authentication"
"How does this project achieve real-time updates?"
"Why is this project faster than alternatives?"
```

### Comparative Learning
```
"How does this compare to React?"
"What's the difference between this and X library?"
"Why would I choose this over alternative Y?"
```

### Architecture Exploration
```
"I want to understand the project structure"
"How do the main components connect?"
"What's the data flow through this system?"
```

## 📚 Recommended Learning Paths

### For Beginners
1. Start with "quick experience" mode
2. Learn core features first
3. Explore implementation later

### For Intermediate Developers
1. Jump to "architecture understanding"
2. Focus on design decisions
3. Compare with alternatives you know

### For Advanced Developers
1. Go directly to implementation details
2. Explore specific algorithms or patterns
3. Consider contributions or forks

## 🐛 Troubleshooting

### "The skill isn't working"
- Make sure you copied the entire `SKILL.md` file
- Check that the file is in the correct directory
- Restart your AI session

### "I'm not getting guided through installation"
- The skill adapts to your responses
- Try being more explicit: "I want to install and try it"
- Make sure you're answering the AI's questions

### "It's moving too fast/slow"
- Tell the AI: "Slow down, I need more detail"
- Or: "Speed up, I just want the highlights"
- The skill adapts to your feedback

### "I don't understand something"
- Just say: "I don't understand this part"
- The skill will explain differently
- Don't be afraid to ask for clarification

## 🎓 Learning Principles Behind This Skill

### Active Learning
- **Do first, read later** - Run projects before studying docs
- **Ask questions** - Curiosity drives deeper understanding
- **Connect to experience** - Link new knowledge to what you know

### Cognitive Science
- **Spaced repetition** - Learn a bit, practice, return for more
- **Retrieval practice** - Answer questions to strengthen memory
- **Dual coding** - See it work + understand how it works

### User Experience
- **Conversation-driven** - Natural dialogue, not lectures
- **Adaptive depth** - Goes as deep as you want
- **Immediate value** - See results in minutes, not hours
