# 学习记录系统设计文档

**日期**: 2026-05-05
**项目**: opensource-project-learning skill
**目标**: 为开源项目学习技能添加学习记录和归档功能

---

## 📋 需求概述

### 核心需求
1. **过程中的学习记录** - 在学习过程中持续记录，方便关闭窗口后重拾进度
2. **学习完成后的归档** - 学习结束后形成完整的档案，方便后续回顾
3. **集成到技能流程** - 这些记录和归档功能应该成为技能流程的一部分

### 用户选择的功能特性
- **存储位置**: 项目内的 `learning/` 目录
- **记录内容**: 完整对话记录 + 结构化摘要（两者都要）
- **恢复方式**: 自动检测并恢复，让用户选择查看记录或直接继续
- **归档输出**: 完整档案（类似 learning-archive-example）
- **目录组织**: 按阶段分目录（stage0/, stage1/等）
- **语言**: 用中文记录
- **多次学习**: 让用户选择继续或新建会话
- **保存时机**: 混合模式（实时保存关键信息，里程碑保存完整对话）
- **完成判定**: 混合模式（手动触发 + 阶段完成时提示）
- **开始记录**: 技能启动时自动创建
- **会话命名**: 用户手动输入主题

## 🏗️ 整体架构

### 核心组件

```
学习记录系统（独立模块）
├── 会话管理器
│   ├── 初始化学习会话
│   ├── 检测已有记录
│   └── 处理会话恢复选择
├── 记录器
│   ├── 实时记录器（保存关键信息）
│   └── 里程碑记录器（保存完整对话）
├── 归档生成器
│   ├── 生成阶段归档
│   └── 生成最终归档
└── 恢复管理器
    ├── 显示学习进度摘要
    └── 加载历史对话
```

### 文件结构

```
项目根目录/
└── learning/
    ├── sessions.json                    # 所有学习会话的元数据
    ├── claude-hud-初探/                 # 用户命名的学习会话
    │   ├── meta.json                    # 会话元信息
    │   ├── progress.json                # 实时进度数据
    │   ├── stage0/                      # 阶段0的记录
    │   │   ├── conversation.md          # 完整对话
    │   │   ├── key-points.md            # 关键知识点
    │   │   └── timestamp.md             # 阶段完成时间
    │   ├── stage1/
    │   │   └── ...
    │   └── final/                       # 最终归档（可选）
    │       ├── summary.md
    │       ├── key-points.md
    │       ├── next-steps.md
    │       ├── progress.json
    │       └── conversation.md
```

### 数据流

```
用户说"帮我学习 claude-hud"
    ↓
[会话管理器] 检测 learning/sessions.json
    ↓
    ├─ 无记录 → 创建新会话 → learning/{用户主题}/
    │
    └─ 有记录 → 显示选项：
        1. 查看之前的学习记录
        2. 继续之前的会话
        3. 创建新的学习会话
    ↓
[记录器] 实时更新当前会话的 progress.json
    ↓
完成阶段 → [里程碑记录器] 生成 stageX/ 的完整文件
    ↓
学习完成 → [归档生成器] 生成 final/ 的完整档案
```

```
[每次用户回复后]
↓

├── 更新 progress.json

│   ├── 已探索的概念

│   └── 时间戳

↓

├── 保存 conversation.md（完整对话）
├── 生成 key-points.md（提取关键点）
├── 更新 progress.json
└── 提示："阶段X已完成！是否生成阶段归档？"

```

## ⚠️ 错误处理和边界情况

### 边界情况处理

#### 1. learning/ 目录被删除或损坏
```
检测：读取 sessions.json 失败
处理：
  - 提示用户："检测到学习记录损坏（或不存在）。
    你想：
    1. 创建新的学习会话
    2. 尝试恢复（如果有备份）"
  - 不中断学习流程，可以继续无记录模式
```

#### 2. 并发访问（多个 Claude Code 窗口）
```
场景：同一项目的多个会话同时写入
处理：
  - 使用文件锁（lock.json）防止并发写入
  - 如果检测到锁，提示："检测到另一个会话正在记录，
    是否继续？"
  - 允许用户选择"强制继续"或"稍后重试"
```

#### 3. 项目路径变化
```
场景：用户移动了项目目录
处理：
  - 在 meta.json 中记录原始路径
  - 检测到路径不匹配时提示："项目路径已变化。
    原路径：/old/path/
    当前路径：/new/path/
    是否更新记录？"
```

#### 4. 磁盘空间不足
```
检测：写入文件失败
处理：
  - 警告用户："磁盘空间不足，无法保存学习记录。
    建议：
    1. 清理磁盘空间
    2. 继续学习但不记录"
  - 不中断学习流程
```

#### 5. 超大对话记录
```
场景：conversation.md 超过 1MB
处理：
  - 自动分割：conversation-part1.md, conversation-part2.md
  - 或提示用户："对话记录较大，是否压缩？"
```

### 错误恢复策略

```
错误级别划分：
🟢 轻微错误：记录失败但学习可继续
  → 记录错误日志，提示用户，继续学习

🟡 中等错误：部分功能受影响
  → 提供变通方案，询问用户选择

🔴 严重错误：无法继续
  → 显示详细错误信息，提供解决建议
```
