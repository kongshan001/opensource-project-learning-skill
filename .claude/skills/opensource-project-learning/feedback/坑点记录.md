## 🔄 处理流程

1. **记录坑点** → 按照上述格式记录到此文件
2. **定期评估** → 使用 `scripts/evaluate-iteration.sh` 评估是否需要迭代
3. **生成方案** → 如需迭代，生成技术方案
4. **评估方案** → Agent 评估方案得分（0-10分）
5. **实施改进** → 得分 ≥9 分则实施，<9 分则继续完善方案（最多3轮）
6. **记录结果** → 将改进记录到 `迭代历史.md`
